# 在线聊天室

支持文字、图片的多人在线聊天应用。

## 功能

- 文字消息实时发送与接收
- 图片发送（点击上传 / 拖拽上传 / 粘贴截图）
- 实时显示在线用户列表
- 用户加入/离开通知
- 消息历史记录（最近100条）
- 正在输入提示
- 图片点击放大预览
- 响应式布局，支持手机和电脑

## 部署方式

### 方式一：Render 部署（推荐，同事在任何网络都能访问）

1. 把代码上传到 GitHub
2. 访问 [render.com](https://render.com)，用 GitHub 账号登录
3. 点击 "New Web Service"
4. 选择你的 GitHub 仓库
5. Render 会自动识别配置，点击 "Create Web Service"
6. 等待部署完成（约2分钟）
7. 获得一个固定公网地址，发给同事即可

> 免费套餐：每月 750 小时运行时间，足够日常使用

### 方式二：本地启动（同事需在同一个局域网）

#### 需要 Node.js

```bash
npm install
npm start
```

启动后把局域网地址分享给同事。

#### 或者使用 Python（无需安装 Node.js）

```bash
python3 start.py
```

### 方式三：纯前端版本（双击打开，仅同一浏览器多标签页可用）

直接双击打开 `chat.html`，在同一浏览器的多个标签页中打开即可互相聊天。

## 项目结构

```
.
├── server.js          # Node.js 服务器（主方案）
├── start.py           # Python 服务器（备选方案）
├── package.json       # 依赖配置
├── render.yaml        # Render 部署配置
├── chat.html          # 纯前端版本
└── public/            # 前端文件
    ├── index.html     # 页面
    ├── style.css      # 样式
    └── app.js         # 前端逻辑
```

## 发送图片的三种方式

1. **点击上传**：输入框上方点击图片按钮，选择文件
2. **拖拽上传**：直接把图片拖到聊天区域
3. **粘贴截图**：截图后按 Ctrl+V（Mac: Command+V）

## 注意事项

- 单张图片限制 5MB
- 消息历史保留最近 100 条
- 支持 jpg、png、gif 等常见格式
